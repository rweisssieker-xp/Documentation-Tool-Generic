## 📖 Verwendung

### GUI
Alle Features sind im Menü verfügbar unter **🚀 Innovation**

### CLI
```bash
# Self-Learning AI
python cli/innovation_cli.py selflearning learn --data '{"type":"test"}'
python cli/innovation_cli.py selflearning save

# Agentic Automation
python cli/innovation_cli.py agentic execute --type documentation

# Hyperautomation
python cli/innovation_cli.py hyperautomation execute --workflow workflow1

# AI Localization
python cli/innovation_cli.py localization translate --text "Hello" --target de

# Compliance
python cli/innovation_cli.py compliance check --file doc.md --standards GDPR,CCPA

# Adaptive UX
python cli/innovation_cli.py adaptiveux adapt --user user1

# Predictive Workflow
python cli/innovation_cli.py predworkflow predict --context '{}'

# Universal Data Hub
python cli/innovation_cli.py datahub connect --type CRM --config '{}'

# Intelligent Assistant
python cli/innovation_cli.py assistant help --question "How to document?"
```
